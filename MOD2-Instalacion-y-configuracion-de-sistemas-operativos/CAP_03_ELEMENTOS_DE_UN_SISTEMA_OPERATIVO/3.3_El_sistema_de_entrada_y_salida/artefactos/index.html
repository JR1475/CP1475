Ejemplo: Escritura de un Archivo en Disco

1. Aplicación: Microsoft Word genera el contenido del documento y solicita al sistema operativo que lo guarde en disco.

2. Kernel: El kernel recibe la solicitud a través de la API del sistema (como write() en sistemas Unix). El subsistema de archivos virtual (VFS) traduce esta solicitud a operaciones específicas del sistema de archivos (NTFS, ext4, etc.).

3. Driver: El kernel envía comandos específicos al driver del controlador de disco (SATA, NVMe, etc.). El driver traduce estas instrucciones a señales que el hardware puede entender.

4. Hardware: El controlador del disco duro/SSD recibe las señales y escribe los datos físicamente en los bloques de almacenamiento del dispositivo.
